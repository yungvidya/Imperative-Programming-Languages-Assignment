# Imperative Programming Languages Assignment

This repository contains the solutions for the Imperative Programming Languages Assignment.

## Q1: Inventory
**File:** `inventory.py`

The program:
- Creates an `inventory` dictionary containing nested dictionaries.
- Stores each item's price and quantity.
- Defines `check_low_stock(threshold)`.
- Loops through the nested inventory and prints items whose quantity is below the threshold.

Run with:

```bash
python inventory.py
```

## Q2: Flight Itinerary Printer
**File:** `flight_itinerary.py`

The program:
- Creates a `flight_route` list containing tuples.
- Each tuple contains a departure city and arrival city.
- Defines `print_itinerary(route_list)`.
- Uses tuple unpacking to separate the departure and arrival cities.

Run with:

```bash
python flight_itinerary.py
```
